# freeCodeCamp Daily Coding Challenges - Solutions

The wonderful people over at [freeCodeCamp](https://www.freecodecamp.org/) have created free [daily coding challenges](https://www.freecodecamp.org/learn/daily-coding-challenge/archive). 
These are simple coding challenges that test your problem solving skills and can usually be completed in under an hour.

When logged in, your freeCodeCamp account will keep track of which challenges you have completed.
However, it does not save a copy of your code solution.
If you want to keep your code solutions to look back on later, you need to save them yourself before pressing the final submit button.
After pressing the final submit button you cannot see that code again.

## How to save the challenges

Create your own repository like this (public or private) to keep copies of your solutions.

Start by trying to solve the challenge.
You can press the *check code* button as much as you want, so long as one test fails.
When all tests pass, the *check code* button turns into the *submit* button.
Pressing the button again at this point will delete your solution.
So don't press it!

As soon as all tests pass, open a new file in the `/challenges` directory.
Paste the prompt into a comment block at the top of the file.
Paste your code solution under the prompt.

Each challenge has an id number, which is found on the [calendar page](https://www.freecodecamp.org/learn/daily-coding-challenge/archive).
I organize the files starting with the number and the name of the challenge.

For example `009-sum-of-squares.js`.

Finally, once it is saved, click the submit button and the challenge will be recorded as complete in your freeCodeCamp account.
